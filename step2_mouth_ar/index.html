Select a tooth, then hold and drag around its edge with Freehand vector border. Release to close and save the smooth border. Draw again to replace that tooth’s border, or choose New tooth for another tooth. Paint and erase are available for pixel corrections.

Run Detect & compare to see the model outline directly over your editable ground truth.

Draw a continuous loop with a mouse, pen or touch—no point-by-point clicking. Release to apply; Escape or Cancel stroke discards an unfinished stroke. After drawing, choose Move border points and drag the white points to refine the selected tooth. Release to update the mask and error. Escape cancels a point move. Undo and Redo restore both borders and pixels. You can also redraw the complete outline. For a pixel-only mask, Smooth existing border creates movable points; check the fitted edge before keeping it. Vector strokes stay 1 screen pixel at any zoom. Painting converts curves back to pixel borders; Undo restores them.

Boundary error uses your vector curves directly; filled pixels are retained for tooth matching and mask export. The background is shared with every result below; switching it never moves labels or changes scores. Use Clean image to check alignment with the photo the model sees. Both uploads must show teeth at the same pixel positions.

Edits update comparison scores immediately and survive Detect & compare. Changing images, crop, extraction settings, or Extract / reset clears edits. Save labels before reloading. Editing labels changes the evaluation, not the model.

Overall boundary comparison

Normalized boundary error (0–1)
—

0 = exact boundary match. Lower is better. This number is the bidirectional Euclidean distance between vector borders, weighted by border length and divided by the selected image region’s diagonal. Use the same region when comparing runs.

Each tooth has its own 4×4 transform (position, rotation, scale) and is projected through a pinhole camera — not a scaled 2D sprite. Tracked: head orientation, from MediaPipe's facial transformation matrix. Measured: each tooth's viewing ray and apparent size, from its segmented contour — the anchor sits exactly on that ray. Estimated: distance along the ray, from a parabolic dental-arch prior. Assumed: metric scale, from an average 50 mm mouth. Depth is not measured and this is not medical-grade registration.
